# Task Management System

A clean, modular and professional task management system developed in Python. It allows users to efficiently manage their daily tasks with data persistence.

## Features

- Add new tasks with title, description and priority
- List all tasks in a well-formatted table
- Search tasks by ID, title or status
- Update task details (title, description, priority and status)
- Delete tasks with confirmation
- Automatic data saving in `tasks.json`
- Clear and helpful user messages
- Input validation to prevent errors

## Requirements

- Python 3.6 or higher
- No external libraries required
